# Rütbe Bakanlığı — Güncelleme Kaynağı

Bu herkese açık depo yalnızca sürüm manifestini ve SHA-256 ile doğrulanan küçük güncelleme yamalarını barındırır.

- `latest.json`: Son sürümü ve yama doğrulama bilgisini bildirir.
- `patches/`: Sürüm başına güncelleme yamaları.
- Güncelleyici herkese açık `raw.githubusercontent.com` adreslerinden yalnızca okuma yapar; GitHub tokeni gerekmez.
- Oyun HTML dosyası, yerel oyun kayıtları, personel verileri ve yedekler bu depoya yüklenmez.
